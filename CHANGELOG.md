# Changelog

## [0.21.0] — 2026-10-28

### DN1Sup SU2Vis (v0.21.0)
- **Разрешения референса — только 1200/1600/2000**: пресеты эскиза
  `1200x900 / 1600x1200 / 2000x1500` (классика 4:3) вместо
  `800x600 / 1024x768 / 1280x960`; дефолт `1600x1200`. Старые пресеты
  в сохранённых настройках нормализуются в дефолт. Финал не тронут.
- **Стиль отображения**: селект «как в модели / белый без теней / эскиз
  для референса» выставляет пачкой белый фон + тени + тонкие линии
  (`sketch_no_shadows` глушит `DisplayShadows` на время снимка);
  ручная правка галочки — «свой набор». Пропорции финала: добавлены
  классические 3:2 / 2:3.
- **Рамки с описанием не теряются при выходе**: чинен emit `BoxEditor`
  (приходил массив вместо `{boxes}` — сцены писались пустыми, примеси
  падали) и добавлен бэкап рамок сцен в файл проекта — переживает выход
  без сохранения `.skp`.
- **Файл проекта — YAML рядом с моделью**: папка `<имя>_su2vis/`
  (например `house_su2vis`) с `su2vis.yaml` вместо `su2vis.json`.
  Читаются все старые форматы (`su2vis/`, `su2vis_<имя>/`,
  `su2vis.json`) — первая запись переезжает в yaml сама.
- **Окно рамок по размеру картинки**: модалка `BoxEditor` больше не
  фиксированная `max-w-3xl` — ширина подстраивается под картинку
  (до 92vw, высота до 70vh).

## [0.20.0] — 2026-10-26
- **Кнопки «Удалить все»** — в примесях (шапка таба, рядом с «Добавить…») и в
  колонке «Рендер» (под кнопкой запуска, с числом файлов; во время рендера
  выключена). Подтверждение двухшаговое прямо в кнопке («Точно удалить все?»,
  сброс через 3 с — нативный confirm() в HtmlDialog недоступен). Ruby:
  `Mixins.clear` / `Gallery.clear` (удаляют картинку + сайдкар, счётчиком
  успехов; `preview_*` и `su2vis.log` не трогаются), мост: `mixins_delete_all`,
  `gallery_delete_all`.
- **Рендеры не перезаписываются**: имя результата строится через
  `Gallery.unique_path` — коллизия по файлу или сайдкару даёт `_2`, `_3`…
  (раньше `File.binwrite` молча затирал старый файл, который не удаляли).
- **Папка проекта `su2vis_<имя модели>`** рядом с .skp (например
  `su2vis_house`): имя чистится от запрещённых в Windows символов, кламп
  60 символов, пустое → `su2vis`. Старые проекты в `su2vis/` продолжают
  работать — фолбэк `Settings.legacy_project_fallback`, пока новая папка не
  создана; `delete_project` принимает оба имени (`project_dirname?`).
- Фронт: кнопки «Удалить все», баннер проекта показывает фактическое имя
  папки, моки моста для новых экшенов.

## [0.19.0] — 2026-10-25
- **Bounding boxes с описанием в сцены и примеси.** Рамки рисуются мышью в
  новом редакторе (`BoxEditor.vue`), у каждой — подпись «что здесь». В генерацию
  уходят дважды: красные пронумерованные рамки рисуются прямо на картинке
  (эскиз сцены / job-копия примеси), а подписи дописываются в промпт
  («Red box 1: …» / «Reference image N: red box 1 — …»); нумерация на картинке
  и в тексте совпадает.
- Сцены: боксы хранятся в атрибутах страницы SketchUp (`boxes_json`) —
  переживают переупорядочивание сцен; на карточке сцены — оверлей рамок и
  счётчик «N рамок»; сохранение — `scenes_boxes_save`.
- Примеси: боксы хранятся в сайдкаре (`boxes`), координаты — в системе
  картинки после crop+rotation (редактор открывается на трансформированном
  превью). Дорисовка на job-копии — через System.Drawing (png/jpg; webp и
  сбой рисовалки → рамки не рисуются и текст боксов в промпт не попадает).
  Кэш аннотаций по размеру+mtime+хеш боксов.
- Ruby: `Scenes.norm_boxes/boxes/save_boxes/boxes_prompt/draw_boxes_png/
  annotated_sketch` (чистый PNG-кодек: рамки + бейдж с номером), `Mixins.
  annotated_job_path` → `[путь, ок]`, `Client.generate(boxes_prompt: …)`,
  `Client.boxes_sentence`.
- Фронт: `BoxEditor.vue` (общий для сцен и примесей), кнопки «▣»/«Рамки…»,
  проброс `boxes` в `activeMixins()`, моки моста.

## [0.12.2] — 2026-10-22
- Корень зависаний превью: рабочие потоки задач голодали без квантов GVL,
  пока главный поток висел в цикле сообщений (наблюдалось: задача торчит

  в `unload!`). С ним превью доходит до done за штатное время без
  ручной помощи.

## [0.12.1] — 2026-10-22

  живых HTTP-соединений (`http_id` задачи), `Jobs.cancel` закрывает сокет
