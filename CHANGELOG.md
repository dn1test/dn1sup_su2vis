# Changelog

## [0.7.0] — 2026-10-22
- Окно «Подключение» (кнопка ⚙ в шапке справа от индикатора): URL студии,
  API-ключ, выбор модели генерации картинок из опроса студии
  (`GET /v1/models`, только `task` с image — LLM, аудио и pup-апсемплер
  скрыты), возможности выбранной модели и image-пайплайна.
- Кнопка «Применить» прописывает все параметры выбранной модели: repo,
  точный gguf-файл (`gguf-variants`, фикс 404 на FLUX.2-klein), steps,
  guidance, workflow, память, лимит стороны финала — по таблице пресетов
  (klein 4/1.0, qwen-image 50/4.0, остальным дефолт студии).
- Шапка показывает подключённую модель рядом со статусом связи.
- Колонки «Сцены» и «Примеси» можно выключить целиком (галочка «вкл»
  в заголовке столбца, хранится в настройках проекта): сцена+примеси,
  только сцена, только примеси или только промпт.
- Без сцены эскиз не снимается: генерация идёт text-to-image (или только
  по примесям), пропорции берутся из общих настроек финала
  (`final_w × final_h`), без `init_image`/`strength` в запросе к студии.
- Чиню моргавшее чёрное окно при старте превью: даунскейл/кроп примесей
  через powershell теперь запускается скрыто (`WScript.Shell.Run(…, SW_HIDE)`
  + `-WindowStyle Hidden`, без `cmd.exe`-редиректа `2> NUL`).

## [0.5.2] — 2026-10-21
- Примеси: чиню выделение мышкой — рамка-индикатор перехватывала mousemove
  посреди drag, выделение замирало и сбрасывалось (теперь у рамки
  pointer-events-none, drag живёт на window-слушателях).
- Карточка примеси показывает отредактированную картинку (кроп+поворот
  на canvas — то же, что уйдёт в генерацию); оригинал — по кнопке
  «оригинал», редактор всегда правит исходник, можно перередактировать.

## [0.5.1] — 2026-10-21
- Примеси: выделение части картинки мышкой («Выделить / повернуть…»):
  рамка на карточке, в генерацию уходит только выделенный фрагмент.
- Примеси: параметр поворота −180…180° (кнопки ±90°, слайдер, точное число),
  применяется к фрагменту после кропа; на карточке бейдж угла.
- Порядок трансформов: кроп исходника → поворот → ужатие до 1024;
  результат кэшируется в `mix_small/` по размеру+mtime+кропу+углу.

## [0.4.0] — 2026-10-21
- Новая колонка «3 · Примеси» после превью: картинки-референсы с подписями
  «что взять» (напр. фактура кирпича). Учитываются и в превью, и в финале:
  файлы добавляются к `reference_images`, подписи дописываются к промпту.
- Хранение — `su2vis/mixins/` в папке проекта (файл + `.json` с подписью
  и флагом), добавление двумя путями: «Добавить…» из браузера и «Из файла…»
  через SketchUp; галочка включает/выключает примесь без удаления.
- Раскладка панели — 5 колонок (Финал → «4 ·», Настройки → «5 ·»),
  ширина диалога увеличена до 1380.

## [0.3.0] — 2026-10-21
- Настройки — свои для каждого файла: папка `su2vis/` (параметры
  `su2vis.json` + `out/`) рядом с `.skp`; при открытии панели предлагает
  создать папку, несохранённую модель просит сохранить.
- Ключ Unsloth Studio — общий (глобальный), остальное — per-file.
- В проекте папка рендеров фиксирована (`su2vis/out`), выбор произвольной
  папки — только в legacy-режиме без проекта.
- Вкладка настроек как в студии: Enhance prompt с тумблером и ✨ Preview,
  Aspect ratio (+ кнопка ⇄) и Resolution вместо селекта режима, слайдеры
  Steps / Guidance / Batch size, Seed с плейсхолдером «Random if empty»
  (пусто = случайно), остальное — под ⚙ Advanced. Режимы 1K/2K из селекта
  убраны (задаются явным разрешением); старые сохранения продолжают работать.
- Кнопка «Удалить папку…» в блоке проекта (двухклик-подтверждение): сносит
  `su2vis/` рядом с файлом, настройки сбрасываются, панель снова предлагает
  создать папку. Чужой путь удалить нельзя.
- Финал: MIME картинки определяется по содержимому (студия отдаёт PNG при
  имени `.jpg`); задача проверяет запись файла и падает с понятной ошибкой,
  а не фантомной карточкой; незагрузившаяся картинка показывает ошибку
  с кнопкой «Повторить» вместо вечной «Загружаю…».

## [0.2.0] — 2026-10-20
- Эскизы снимаются пакетно на главном потоке до старта задачи (write_image
  из рабочего потока отдавал устаревший кадр — вторая сцена не совпадала).
- Каждая сцена — отдельная задача; живой прогресс денойза; журнал во вкладке
- настроек; batch-варианты превью; enhance_prompt, upscale, workflow;
- fit_size сохраняет пропорции у границ 256/2048.
- Кнопка ⟳ записывает текущий вид окна в сцену.

## [0.1.0] — 2026-10-20
- Первый скелет расширения: панель Vue 3 + Tailwind (сцены, настройки, превью малого разрешения, финал с тем же seed).
- Клиент Unsloth Studio с `seed` + `strength` и VRAM-фолбэком.
