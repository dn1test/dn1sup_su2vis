# sketch2photo

Ruby-скрипт, который превращает эскизы в фотореалистичные картинки через
локальный **Unsloth Studio** (движок diffusers, модель **flux-3-image-klein**,
reference workflow). Полностью локально и бесплатно: без MiniMax, без VPN,
без ключей провайдеров.

## Структура

```
.
├── sketch2photo.rb
├── config.yaml   # базовые настройки (промпт, размеры, папки)
├── in/           # сюда кладём исходные картинки (эскизы)
└── out/          # сюда попадут результаты
```

## Требования

* Ruby ≥ 3.0
* [Unsloth Studio](https://unsloth.ai) с поддержкой image inference
* NVIDIA GPU: 8GB+ VRAM для Q4_K_XL GGUF, 24GB+ для 2K
* интернет только один раз — чтобы скачать веса модели

## Запуск студии

```bash
unsloth studio --api-only -H 127.0.0.1 -p 8888
```

Ключ студии: кнопка **API keys** в интерфейсе студии → вставить в `config.yaml`
(`unsloth_key`) или переменную окружения `UNSLOTH_API_KEY`.

## Запуск

```bash
# по умолчанию возьмёт все картинки из ./in с настройками из config.yaml
ruby sketch2photo.rb

# с указанием конкретных файлов
ruby sketch2photo.rb in/cover_1.png in/cover_2.png

# CLI-аргумент перебивает config.yaml
ruby sketch2photo.rb --prompt "Photorealistic product render, studio lighting" --ratio 1:1 --res 2K
```

Скрипт сам загрузит модель в студию при старте (первый раз — скачивание весов,
дальше секунды) и следит за прогрессом.

## Настройки: config.yaml

| параметр | что делает | дефолт |
|------------------|----------------------------------------------------|-------------------------------|
| `prompt` | текст промпта для модели | встроенный (фотореализм + человек) |
| `suffix` | суффикс имени выходного файла | `_photorealistic` |
| `ext` | расширение имени выходного файла | `jpg` |
| `in` / `out` | входная / выходная папки | `./in` / `./out` |
| `unsloth_url` | адрес API студии | `http://127.0.0.1:8888` |
| `unsloth_key` | API ключ студии (или `UNSLOTH_API_KEY`) | — |
| `unsloth_model` | HF-репозиторий модели | `unsloth/flux-3-image-klein-GGUF` |
| `unsloth_gguf` | GGUF-квант внутри репозитория | `flux-3-image-klein-UD-Q4_K_XL.gguf` |
| `unsloth_steps` | шаги denoise (distilled: строго 4) | `4` |
| `unsloth_guidance` | guidance scale | `1.0` |
| `unsloth_allow_oversized` | как тумблер UI «Allow oversized generations»: генерировать, даже если оценка VRAM говорит, что не влезет | `true` |
| `unsloth_memory_mode` | политика памяти при загрузке, аналог «CPU offload»: `auto` / `fast` / `balanced` / `low_vram` | `balanced` |

Примечания:
* Генерация идёт в точных размерах эскиза (кратно 16, максимум 2048 по API
  студии); пропорции и разрешение = как у входа.
* `allow_oversized: true` повторяет тумблер UI: студия выполняет 2048, даже если
  её оценка VRAM против. По доке студии такой прогон может упасть с OOM или —
  на Windows — уползти в системную RAM и идти очень медленно.
* Если для размера эскиза не хватает VRAM и oversized выключен (`--no-allow-oversized`),
  скрипт автоматически уменьшает разрешение (с сохранением пропорций) и повторяет.
* Водяного знака у локального klein нет.
* Студия отдаёт PNG; `ext` влияет только на имя файла.
* Файлы в `in/` могут быть с «неправильным» расширением — скрипт определяет
  формат по содержимому.

## Как это работает

1. Скрипт берёт каждую картинку из `in/` (или перечисленную в аргументах)
2. Готовит data-URL (формат определяется по содержимому)
3. Отправляет в студию: `prompt` + картинка-референс → flux-3-klein дорисовывает
   фотореализм, сохраняя композицию, геометрию и масштаб
4. Результат сохраняется в `out/<имя><suffix>_ГГГГММДД_ЧЧММСС.<ext>`

## Если что-то пошло не так

| Проблема | Решение |
|---|---|
| `HTTP 401` от студии | неверный/старый `unsloth_key` — создайте новый в интерфейсе студии |
| `needs about N GB ... only ... usable` | скрипт сам подбирает разрешение; если повторяется — эскиз слишком большой, уменьшите его |
| `No such file or directory` при генерации | студия не запущена — `unsloth studio --api-only -H 127.0.0.1 -p 8888` |

## CLI-флаги

```
--config FILE      путь к YAML с настройками (./config.yaml)
--prompt TEXT      текст промпта
--suffix STR       суффикс выходного имени (_photorealistic)
--ext EXT          jpg / png (имя файла)
--in DIR           входная папка (./in)
--out DIR          выходная папка (./out)
--unsloth-key KEY  ключ Unsloth Studio (или UNSLOTH_API_KEY)
-h / --help        справка
```
